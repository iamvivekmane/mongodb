# 🍃 MongoDB Learning

Hands-on notes and practice as I learn MongoDB — from basic CRUD operations to aggregation and indexing.

---

## 📖 What's Inside

### Day 01 — CRUD Basics
- Inserted multiple documents using `insertMany()` in a sample e-commerce database
- Practiced reading data: querying, **projection**, **sorting**, and **limiting** results

### Day 02 — Updating & Deleting
- Updated documents in MongoDB using update operators
- Deleted documents from collections
- Cleaned up file/folder naming for consistency

### Day 03 — Aggregation
- Explored the **aggregation framework** and aggregate functions for summarizing and transforming data

### Day 04 — Indexing
- Learned how **indexes** work in MongoDB and how they improve query performance
